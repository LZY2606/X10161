# 网络会话重组台（reasm）

一个**完全离线、零外部依赖**的 Rust 本地服务，用于在浏览器里把简化 pcap 或项目自定义的
确定性帧夹具**重新装配成 TCP 会话**——解析链路层 / IPv4 / IPv6 / TCP 元数据，归并双向流，
呈现每个方向的序号区间、重传、缺口、乱序与最终重组字节。程序不调用系统抓包权限，也不读取
任何实时网卡。

## 安装与演示

```bash
cargo build --locked

cargo test --all-targets
cargo run --locked -- --addr 127.0.0.1:5235
# 浏览器打开 http://127.0.0.1:5235 ，页面标题为“网络会话重组台”
```

可选参数：`--data-dir DIR`（默认 `reasm-data`）。

## 输入

- **经典 libpcap（.pcap）**：自动识别大小端与微秒/纳秒时间戳，支持以太网（DLT_EN10MB）、
  原生 IP（DLT_RAW）与 Linux cooked（DLT_LINUX_SLL），兼容单层/双层 802.1Q。
  pcapng 不在支持范围内（返回明确错误）。
- **确定性夹具 JSON**：帧按数组顺序作为“原始帧序号”，时间戳用整数微秒，帧字节用十六进制：

```json
{
  "format": "reasm-fixture/1",
  "link_type": "ethernet",
  "frames": [
    { "us": 1000, "hex": "001122334455 66778899aabb 0800 4500...." },
    { "us": 2000, "hex": "..." }
  ]
}
```

`GET /api/sample` 提供内置示例夹具（同一份 JSON 可直接上传）。

## 重组语义

- **连接识别与代次**：不只看四元组。SYN、FIN、RST 与空闲超时共同决定“代次（generation）”：
  - RST 立即结束当前代次；双向 FIN 均被确认则优雅关闭；
  - 同四元组新 SYN 产生新一代，旧连接仍开着时旧代记为 `reused`；
  - 相邻段时间差超过空闲超时（默认 120s，页面可改）会断代；
  - SYN 重传、三次握手中的 SYN+ACK 不会误换代。
- **partial 会话**：抓包在会话中间开始（没有任何 SYN）也能建立 `partial` 代次，
  但**绝不伪造握手**；base 序号取首个数据段序号。
- **32 位环绕序号**：按 RFC 1982 串行算术比较（2³¹ 窗口），所有相对偏移建立在
  观测到的 base 之上。
- **重叠策略（可配置）**：
  - `first-seen`（默认）：先到的字节保留；
  - `last-seen`：后到的字节覆盖；
  - 无论哪种策略，被覆盖的字节都作为碰撞证据保留（旧值/新值/帧号/是否替换）。
- **IP 分片**：先按 IP 层自身边界重组；重叠、超预算、片数过多、协议不一致或畸形偏移都会让
  对应数据报进入**隔离（quarantine）**，只在证据中列出，不影响任何其他会话。
- **时间排序**：全部以 `(微秒时间戳, 原始帧序号)` 排序；相同时间戳时帧序号决胜，
  FIN/RST 竞态也按此顺序记录。
- **校验和**：校验 IPv4 首部校验和及 IPv4/IPv6 TCP 伪首部校验和；异常帧继续参与组装，
  但在证据中逐帧标出，不静默丢弃。

## 界面能力

上传夹具 / pcap、按端点或状态（partial、RST、FIN、超时、复用、有缺口）筛选会话、
查看每个方向的序号空间与片段覆盖条、切换重叠策略并调整超时、逐段查看重传/乱序/碰撞证据，
并下载：

- 每个会话方向的连续前缀重组字节（`<generation>.<A|B>.bin`）；
- 完整证据 JSON（人类可读缩进，指纹使用键排序的规范形式）；
- 规范化后的 canonical pcap（抓包页链接）。

## 内容寻址与分析版本

- 原始帧按 SHA-256 内容寻址存入 `data-dir/blobs`（自动去重）。
- 抓包身份由 `(link_type, [(时间戳, 帧字节哈希, 原始长度)…])` 的规范化哈希决定；
  因此**夹具导出再导入与等价 pcap 往返得到相同身份与结果指纹**。
- 分析身份由 `analyzer 版本 + 抓包身份 + 规范化配置` 决定。改变重叠策略/超时会生成
  **新分析版本**，旧版本永不覆盖；相同配置重复分析幂等命中同一版本。
- 结果指纹 = 规范化证据 JSON 的 SHA-256。

## 代码结构

| 模块 | 职责 |
| --- | --- |
| `src/wire.rs` | 以太网 / IPv4 / IPv6（含扩展、分片扩展）/ TCP 解析与校验和 |
| `src/frag.rs` | IP 分片重组、重叠/超预算隔离 |
| `src/pcap.rs` | 经典 pcap 读取与编码 |
| `src/fixture.rs` | 确定性夹具 JSON 导入 |
| `src/builder.rs` | 测试与示例用的确定性帧构造器（含手动 IPv4 分片） |
| `src/seq.rs` | 32 位环绕序号、可配置 first/last 策略的字节覆盖空间 |
| `src/reasm.rs` | 数据报交付、会话/代次状态机、双向重组与证据 JSON |
| `src/store.rs` | 内容寻址存储、抓包导入、分析版本与指纹 |
| `src/server.rs` + `web/index.html` | 标准库 HTTP 服务与单文件前端 |

测试使用 `src/builder.rs` 构造序号环绕、重传、乱序、缺口、四元组复用、中途抓取、
FIN/RST 竞态、IPv4 分片重叠与相同时间戳等场景，并断言导入/导出后结果指纹一致。
